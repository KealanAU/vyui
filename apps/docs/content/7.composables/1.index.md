Vy UI exports composables from two packages. `@vyui/kit` has a handful of app-facing helpers you'll reach for directly. `@vyui/core` has those plus a set of primitive-authoring utilities that mirror Radix Vue / Reka UI's own exports, which most app code never touches directly.

## App composables

From `@vyui/kit`:

- [useAppConfig](/composables/use-app-config) reads the merged `AppConfig`.
- [useColorMode](/composables/use-color-mode) exposes the reactive light/dark/system mode.
- [useComponentIcons](/composables/use-component-icons) resolves leading, trailing, and loading icons.
- [useTray](/composables/use-tray) gives imperative navigation for an ancestor `VyTray`.

## Device & host

From `@vyui/core` come the seams between the bundle and the native container. [Sparkling](/guides/sparkling) handles this wiring for you; see the [native host integration guide](/guides/native-host-integration) only if you are building a custom host.

- [useSafeArea](/composables/use-safe-area) returns normalized notch, Dynamic Island, and home-indicator insets.
- [useGlobalEvent](/composables/use-global-event) subscribes to native-to-JS global events with cleanup.
- [getViewportSize](/composables/get-viewport-size) reports the LynxView's size in logical px.

## Internationalization

From `@vyui/core`. See [i18n composables](/composables/i18n-composables) for the short version, or the full [i18n](/i18n) page for the complete story.

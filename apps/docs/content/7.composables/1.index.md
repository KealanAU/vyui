Vy UI exports composables from two packages. `@vyui/kit` has a handful of app-facing helpers you'll reach for directly. `@vyui/core` has those plus a set of primitive-authoring utilities that mirror Radix Vue / Reka UI's own exports — most app code never touches these directly.

## App composables

From `@vyui/kit`:

- [useAppConfig](/composables/use-app-config) — read the merged `AppConfig`.
- [useColorMode](/composables/use-color-mode) — reactive light/dark/system mode.
- [useComponentIcons](/composables/use-component-icons) — leading/trailing/loading icon resolution.
- [useTray](/composables/use-tray) — imperative navigation for an ancestor `VyTray`.

## Internationalization

From `@vyui/core`. See [i18n composables](/composables/i18n-composables) for the short version, or the full [i18n](/i18n) page for the complete story.

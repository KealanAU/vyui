`@vyui/kit` ships a real theme system today — every styled component has its own theme file backed by [Tailwind Variants](https://www.tailwind-variants.org), and the whole thing is overridable at runtime.

- [Overrides](/theming/overrides) — per-component theme files, `createTv` / `tv`, and runtime app config.
- [Colors](/theming/colors) — the three CSS-variable tiers, configuring and adding colors.
- [Dark Mode](/theming/dark-mode) — `useColorMode` and the app-root contract.
- [Fonts](/theming/fonts) — registering and applying fonts across web and native.

Pick a page from the sidebar to get started.

Vy UI is a two-layer component system for [Vue-Lynx](https://vue.lynxjs.org/) — the Vue bindings for [Lynx](https://lynxjs.org/), ByteDance's open-source native cross-platform framework. It brings Radix-style headless primitives — and an optional opinionated styled kit — to a runtime that doesn't render HTML.

## Status

Vy UI is **pre-alpha**. Vue-Lynx itself is pre-alpha. Expect breaking changes to component names, props, and slots. Things will break. Don't ship this to production yet.

## What's inside

- **Native-first** — primitives target Lynx's `<view>` / `<text>` rendering model, not the DOM.
- **Zero styling opinions** — `@vyui/core` ships behavior, you bring tokens. `@vyui/kit` adds a themeable layer when you want it.
- **Tailwind Variants** — `createTv()` and `tv()` are re-exported from kit so you can extend the theme like you would with Nuxt UI or shadcn.

`@vyui/core` ships an `<Icon>` primitive that accepts any [Iconify](https://icones.js.org) name. There is no bundled icon set — pick a collection, install the `@iconify-json` package, and use it.

::code-group
```bash [pnpm]
pnpm add @iconify-json/lucide
```

```bash [yarn]
yarn add @iconify-json/lucide
```

```bash [bun]
bun add @iconify-json/lucide
```

```bash [deno]
deno add npm:@iconify-json/lucide
```

```bash [npm]
npm install @iconify-json/lucide
```
::

```vue [App.vue]
<script setup>
import { Icon } from '@vyui/core'
</script>

<template>
  <Icon name="i-lucide-sparkles" :size="20" color="#6366f1" />
</template>
```

Names work in either form — `i-lucide-folder` or `lucide:folder`. Browse 200,000+ icons at [icones.js.org](https://icones.js.org).

::callout{icon="i-lucide-info"}
Lynx's native `<svg>` rasterizes the XML and can't inherit `currentColor` from a surrounding `<text>`, so the `color` prop is required to tint an icon.
::
